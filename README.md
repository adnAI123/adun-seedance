# adun-seedance

用即梦 Seedance 2.5 拍 AI 短剧、漫剧和广告时，把剧本变成视频提示词的一套导演工序。装进 Claude、Codex、豆包这类 AI 之后，你给它剧本和参考图，它先像导演一样把这场戏设计出来，你点头了，它再写成能直接丢进即梦跑的提示词。

## 它和提示词模板有什么不同

提示词库给你的是词和模板，你还是得自己想这场戏怎么拍。这套工序先替你想戏，再替你写字，中间停下来等你点头：

1. 先当导演。读完剧本和参考图，从仓库里挑一两篇同类型的实拍提示词对齐水准，然后只谈怎么拍，不写提示词。方向还没定，它会代入三位适合这场戏的世界级导演，各出一版从开拍讲到收尾的构想，三版的看法、情绪切入点和调度都不一样，再告诉你它推荐哪一版、为什么。方向定了，就深化成一份能在脑子里从头放到尾的导演设计。
2. 再落笔。你认可了设计，它才写成一条 Seedance 2.5 能独立执行的提示词，正文四块：总则；参考图、尺度与空间坐标；时间块；三层声音。视频模型记不住上一条，所以每个人站在哪、面朝哪、兵器在谁手里、机位在哪一侧、谁被打到了哪，都在这一条里写全。
3. 交稿前自查四件事：只读正文看不看得懂；观众该在哪一刻看懂的，有没有提前泄底；最重的那一下保没保住、秒数够不够；空间和道具前后对不对得上。

为什么分两步：设计时不管措辞，就不会因为怕难写，去挑稳妥的机位、压低表演、缩小奇观；写字时只管把定下来的戏写准，不再改戏。

## 你需要什么

- 一个能装 Skill 的 AI：Claude Code、Codex、豆包工作、扣子、Claude 网页版等。
- 即梦账号，用 Seedance 2.5 生成。
- 剧本和参考图。图越全，它写得越准。

它写一段戏大约要读 3 到 4 万字的规则和案例，用长上下文的模型效果更稳。

## 安装

### 一、命令

```bash
npx skills add adnAI123/adun-seedance -g
```

Claude Code、Codex、Cursor、Gemini CLI、Trae 等都认这条，会让你选装进哪个 AI。需要 Node.js 22.20 以上。以后更新跑 `npx skills update`。

这条命令也可以直接发给豆包工作这类 AI，让它替你跑。

Claude Code 也可以用插件命令：

```
/plugin marketplace add adnAI123/adun-seedance
/plugin install adun-seedance@adun-seedance
```

### 二、把链接丢给 AI

```
安装这个 skill：https://github.com/adnAI123/adun-seedance
```

### 三、下载压缩包

前两种都不行的，到 [Releases](https://github.com/adnAI123/adun-seedance/releases/latest) 下载 `adun-seedance-v3.zip`，在它的技能页面上传。豆包电脑版在「插件·技能·伙伴 → 技能 → + → 上传技能」；Claude 网页版在 Skills 设置里，上传前先打开代码执行。

## 怎么用

- 说「用 adun-seedance-v3 设计这一段」，再把剧本和参考图给它。直接让它写 Seedance、即梦的视频提示词或分镜，它也会自己调用。
- 参考图就是事实：人物长什么样、场地什么格局、光从哪来，都以图为准。
- 它会先交导演设计。你选定、认可之后说「写提示词」，它才动笔。
- 分镜你已经想好了、只要提示词，直接说，它跳过设计。
- 拍系列，让它照 `templates/PROJECT.md` 建一份项目档案，放在你自己的文件夹里，记画风、人物、道具和已经拍完的段落。哪一段成片你满意了，说「存档」，它再写进档案。
- 成片拍歪了，把成片给它，它会对着设计查是哪一句写出的问题，再改。

## 看案例时注意

- 每篇原件都是当时真跑过的原文，一字没改。里面有些写法后来不用了，成片也有拍偏的地方，都在索引每一条的「注」里写明了，照着学之前先看一眼。现在怎么写，以 `core/format.md` 为准。
- 原件里的人物、招式和机位只属于那一场戏。学它怎么想、怎么写，别换个皮照抄。
- `早期标杆/` 里有几条是同人练习稿，带着原作角色名。即梦对正在热播的大 IP 角色名会拦，自己写的时候换成外形代称，做法见 `core/platform.md` 第二章。
- 平台参数和审核经验记录到 2026 年 11 月。即梦更新了，以官方说明为准。

# 白模分册

> 本分册汇总白模参考的适用判断、搭与渲流程、提示词两档写法、生成排错与 Blender 技术坑。白模默认不得主动启用；仅在用户明确提出要求，或针对当前复杂空间调度有充分具体理由向用户提议并获同意后执行。

---

## 一、各场景使用经验（供提议或评估参考，非自动执行指令）

| 场面特征 | 实测效果与取舍参考 |
|---|---|
| 多人戏里摄影机在人群中连续穿行、升降的长镜头 | 几何可直接锁住切点、运镜路径、人物在画框中的大小与出入画时机 |
| 悬殊巨物尺度、复杂三维升降穿越 | 空间体积与高低比例可由灰盒直观定死 |
| 机位基本固定、靠正反打和反应镜推进的文戏 | 通常无需白模；需核对视线与背景时用简明俯视图推算即可 |
| 涉及极多需辨认身份角色的长段 | 白模只锁位置不锁身份，人过多仍易串脸串词；可考虑拆段或文字空间锚点 |
| 高速近身打斗、快切、强形变特效为主 | 作者实测粗灰盒直线运动易被照抄导致打斗僵硬、占位球易被画成实物；群战若经授权使用，宜走宽松档只借站位比例、动作另给 |
| 一两人近景表演、短补镜 | 文字直写表演更自然 |

## 二、搭白模之前

1. 须在导演分镜设计已获用户确认、且用户明确授权做白模后才动手；已有同场景白模工程优先复用、局部修改，不做未经要求的精细建模、复杂绑定或反复渲染。
2. **严格按定案搭建**：人物站位、朝向、路线与切点严格服从已确认的导演定案，不自行移动已锁定的人位；搭设中若发现定案机位与视野遮挡存在真实几何冲突，报明冲突请用户确认调整方案。
3. 逐镜核对视野：用视野计算或光线投射确认每镜画内有谁、背景是什么，用于把该镜背景与入画人物写准。
4. 白模切点跟随定案动作节奏，与文字时间轴保持一致，不为凑整数秒改动动作节奏。

---

## 三、搭与渲

1. 先出关键预览帧拼成接触表核对构图与遮挡，确认后再渲整段 mp4；渲完抽帧逐一核对切点前后两帧。
2. 代理体颜色两两明显拉开（冷暖或深浅至少拉开一项）；披风、翅膀等附件只用本人主色的深浅，不撞他人主色。
3. **粗颗粒度白模官方建议优先不带四肢与翅膀**；若带了四肢翅膀，必须在提示词中写出完整的四肢动作序列，否则极易动作僵化。细颗粒度白模上传前必须去掉轨迹线、坐标线与相机锥（camera cone）等辅助线。

## 四、提示词写法（挂白模视频时）

### 1. 官方两档公式
- **粗颗粒度（球体／圆柱／方块拼搭动态骨架，从零渲染画面，官方建议优先用此档）**：
  `【参考声明】参考@视频1的运镜、动作动线、角色站位与镜头切接，白模的纯色、几何面孔与灰背景不进入成片 + 【对应关系映射】将@视频1中的[颜色与形状特征]模型替换为@角色图A的[角色名]…… + 【剧情详述】按时间线写满动作、表演、台词与光影 + 【场景与收束】@场景图及整体画风质感与固定要求`
  - 宽松用法（官方示例，适合巨物对打、群战调度）：写明只参考白模的角色大小关系、站位方向、镜头距离与空间压迫感，不照抄白模动作，最终画面不留白模质感；动作可另挂参考视频并限定时间段。
- **细颗粒度（建模完整、结构清晰，仅换材质光影渲染）**：
  `将@视频1的白模动画渲染成最终成片 + 按时间段描述背景环境、色调氛围、人物材质与光影效果（含转场点） + @场景图及整体风格一致性收束`

### 2. 代理体映射与防串人经验
- 每个颜色形状的人形、座椅、台阶、圆盘、球体等占位物逐一说明对应哪张图的谁或什么器物；占位物与人体留出适当间距，防模型把紧贴的长杆或方块误读为手持物。
- 非热门拦截 IP 角色直接用本名；灰盒人人同形易串脸时，补充独有外形区分特征。
- 两种绑定方式可按需选用：①开头集中列全部人物与白模颜色映射，时间块只叫名字；②开头写白模、场景与群众占位，每镜出现谁就在该镜内 `@` 谁并标明颜色与画内位置。用到主景与反打多张场景图时，在对应时间段标明所用场景图。

## 五、生成排错对照与 Blender 技术坑

| 症状 | 常见原因 | 调整办法 |
|---|---|---|
| 人物互换、串脸 | 泛称或长代称；两人特征重叠；代理体颜色相近或附件撞色 | 用本名（大 IP 用固定短代称）＋区分特征；拉开代理体颜色 |
| 背景冒出现编闲人 | 认得出的人未挂图，只写了笼统群称 | 认得出的人挂图写清；认不出的写成焦外虚影；画外无关人不提 |
| 手里多出怪异物件 | 灰盒里长杆或方块紧贴人体 | 拉开占位物与人体间距，映射里写明该物身份与位置 |
| 台词串到别人嘴里 | 多人同框未标清说话人与听者 | 台词前标清说话人及嗓音，画外音镜写明画内听者闭嘴 |
| 动作僵硬像木偶 | 快切打斗套用了粗灰盒，或带四肢灰盒未写全四肢动作 | 打斗撤白模或改宽松档；文字把肢体发力与表情写具体 |

**Blender 常见技术坑**：①积木脚本把尺寸写进 `scale` 时，打缩放关键帧须写回原尺寸（写 `1` 会变一米大方块挡死镜头）；②隐藏帧与出现帧至少隔 `0.05s`（落在同一帧会让物体从首帧慢慢长出）；③`21:9` 竖向视角较窄（35mm 上下各约 12 度），半空人物与高处物须同时核对水平与竖直视野；④追拍镜头瞄准人本身，勿瞄准目的地防人出画；⑤光线投射认人沿父级链往上查；⑥`qlmanage` 缩略图会裁切非正方形画布，导出预览前先把 svg 设为正方形；⑦做了时间重映射后，注意区分设计稿时间与成片时间；⑧正上方俯拍瞄准点微偏一点，避免正垂直时镜头朝向退化。

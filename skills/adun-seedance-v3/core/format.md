# 阿墩 Seedance V3 · 提示词落笔册

本册在导演设计获用户认可后（或用户已给出定案分镜直接要求写提示词时）读取，由作出设计的同一位导演落笔，全程受主册「最高总纲」统摄。

职责是把定案的那部电影准确写成一条可由 Seedance 2.5 独立执行的提示词。生成模型没有跨段记忆，也看不到前面的讨论，每一拍的视点、表演、空间、受力因果、揭晓时机与余势，都必须单凭本条正文与实际绑定的参考成立。把定案中已经摆通的大胆调度、视角与尺度，用极其严谨的空间几何、朝向纵深、遮挡层次、路线账与物件账焊死在画框里——靠写准空间托住设计，绝不因难写而把定案镜头改平。

格式只负责把已经决定的电影写准确，没有自行增删镜头、改走位、换说话方式或挪动高潮的权力。落笔中若发现某一拍在视野、时间、素材或机器执行上有具体冲突，指出冲突回到那一拍处理；涉及改动已认可的拍法，先向用户说明。

设备参数、素材规格、`@` 引用、审核与大 IP 代称、专项能力公式，按需查 `core/platform.md`。有成片需审改、补拍或存档时读 `core/维护.md`；经用户同意启用白模时读 `core/baimo.md`。

## 一、四块纯文本结构

提示词正文输出纯文本，不用 Markdown 标题（`#`）、星号加粗（`**`）或列表符号；双引号只用于角色说出的台词和画面里本来就有的文字（如牌匾、字幅、屏幕字），其余描写一律不用双引号。画幅比例在生成参数里选，不裸写进正文（`变形宽幅镜头` 等镜头光学质感词照写）。设计说明、待补素材与上传对应清单放在正文之外，按用户需要附交。

正文按四块一气呵成组织（首段与第二块可连成一段，也可在块间换行；分镜按时间块换行；音效收尾）：

### 1. 首段总则
写清本段时长、题材定位；用一两句讲完这一段的因果：谁对谁做了什么，对方怎么接，结果怎样。画风、动作与运镜、冲击与破坏，定案各取了哪部作品的什么就写什么（画风写到光影影调与质感，动作写到速度与节奏，冲击写到规模与受力）。再写本段核心视觉奇观或关键动态的物理运动过程、对齐场景参考图的色彩冷暖与主光空气质感（同一场景拆多条连续生成时，首段复用同一套主光方向、冷暖色温与反差基调防跨条跑色）、摄影胶片质感与适用的固定要求。最后写整段的拍法：镜头钉着拍还是贴着人和兵器走，哪一下降速、其余什么速度，全段分几截。
- 核心动态与奇观在这里写透机理：是什么材质、怎样运动、光怎样落到人物和器物上、力量怎样改变这个场地。文戏则抓准决定本场观感的光影、风雾、空间质地与声场基调。
- 器材与光学质感写成附着在具体景物上的可见证据（如高速快门抓清飞溅火星与水滴；变形宽幅镜头使焦外烛火或火星化作拉长的竖向椭圆光斑、单一强光源拉出一道克制的横向眩光；高反差暗面拍摄时写明暗部深邃但保留皮肤衣料纹理、面部清晰可读不压成死黑；写实近景保留原生皮肤毛孔与肌理、毛发根根分明；风格化动画用线条粗细与阴影分段锁定）。
- 字幕、水印、标识与配乐要求全篇集中写一次，默认写：`全程无字幕、无水印、无LOGO、无BGM。` 用户指定配乐或由音频驱动时，按本段要求调整。
- 要在本段中途才第一次显露的变身、伤势、断器或底牌，留到它出现的那一个时间块写，不在总则提前亮底。

### 2. 参考图、尺度与空间坐标
- **素材绑定**：场景图在人物之前，随身兵器与坐骑跟持有者写在同一句。已命名素材用无文件后缀的 `@素材名`；只有编号的素材按本段实际上传顺序写 `@图片1`、`@视频1`、`@音频1`（大 IP 正文代称与多模态引用细则见 `core/platform.md`；用户要求逐镜引用时，落到对应时间块）。
- **有效特征与当前状态**：从图中选出影响本段辨认、光影、动作与受力的特征（多人同场或混战时，全篇可用固定的两到四字颜色衣冠短前缀直呼角色防串脸，如 `黑金袍通天`、`白发金袍老子`、`金冠多宝`），以及此刻偏离原图的现状（如伤损、衣袍破损、持物变化；带纯色棚拍背景或多视图并列构图的参考图，注明只取人物面貌与服饰器物本体，不采用纯色背景、并列构图及原图中本段不用的站姿或持物姿势）。兵器、法宝、坐骑写清全段的账：在谁哪只手里，是不是始终同一件实体；中途放大、缩回、脱手、换成另一件或断掉的，写明第几秒变、变完手里是什么（原处是否空出），后面它再出现的那一块再点一次。不把图上已有且与本段戏无关的繁琐陈设抄成说明书。角色挂有音色参考时写明 `@音频N` 归属，情绪与念法服从当场表演。变身过程段挂变前变后两张图按时间顺序写，已变完的段只挂变后图。
- **尺度与空间坐标**：有巨物或悬殊体型同框时，给直观对比标尺与倍数（如法宝相当于城中阙楼十二倍、常人不到一根手指长；同框那一镜再写清各自占画框多大）。用图上看得见的地标（已有明确方位坐标则沿用，殿门与莲台、门内与门外已清楚的场景可直接用实物相对关系；无参照物的云海虚空用双方相向关系与攻势来路）说明场景图视点朝向；同一场地挂正反两张场景图时，各说明从哪头看、朝哪边拍取哪一张。钉清在场每个人与物的起拍位置、朝向、高低、距离与姿态，凌空的写依据（脚下无支撑、衣摆垂空）；成排成阵的写队形、依次是谁、谁隔着什么正对谁、哪几座空着；在场而不在戏里的人群写所在范围与状态、哪一片无人；场地已有的破损陈设与受光分布一并写明。写明摄影机所守轴线一侧（多向切镜的殿堂或阵地戏写清朝哪头拍背景是什么；高速交锋中摄影机进场贴身跟随，沿途地标写成从身侧掠过）。本段路线单写一串：谁全程不挪，谁先到哪，哪一下把谁打向哪、谁追到哪，最后各自停在哪；侧拍时谁在画左谁在画右，攻势从画面哪边到哪边，被打回去又是哪边到哪边。换位、升降或越轴按定案写出连续运动交代。连续段把上段留下的位置、物态伤损、动势与人物心境，落实为起拍当下看得见、听得见的状态，不写「接上段」「照旧」。

### 3. 时间块
- 时间码用整数秒（如 `00:00-00:05`、`00:12-00:22`；半秒降速或块内子切点直接写进句子里，不为半秒特写或单步动作拆小数秒碎块；音乐重拍卡点可用帧号）。时间块可以是一镜，可以是同一长镜头的连续变化（一镜到底写明 `一镜到底长镜头全程不切镜头`；景别纯靠机位或人物移动变化时可写明 `全程焦距锁定，景别变化全部由机位移动完成`），也可以是一截戏里连切几镜，块内的切点写明落在第几秒或哪个动作上。
- 每块开头写三样。怎么接：接上一块的哪个动作、哪股余势、哪一下接触或哪一声响；切镜写 `切`、`硬切`、`动作匹配切` 或借什么（如炸散云絮、扑面碎石、倒卷黑雾、人物视线）甩过去，同一镜往下走的照直写；第一块写第一帧已经在发生什么。镜头在哪：在谁的哪一侧、前后高低，什么景别，焦段在要它的透视时写（人脸近景与特写用 50 或 85 毫米，不用 24 毫米近怼人脸防五官畸变；近景与特写背后写成焦外轮廓、光斑与颜色）。镜头怎么动：跟谁、怎么走，被冲击推开再追回还是钉住不动，运镜名可在括号里附英文术语（如 `leading tracking`、`following tracking`、`whip pan`、`arc shot`、`dolly in`、`locked-off`）。随后把画内主体占比、动作、力道传导、对方反应与环境后果连成一条不断气的流水句，块尾停在交给下一块的那个动作或去向上；最后一块写明最后一帧停在什么上、还在不在动。句子的先后就是画面的先后，同一瞬发生的事写进同一分句。
- 台词按定案原文嵌入对应时间块，写清谁说、对谁说、什么嗓音口吻、哪几个字与哪个动作相遇（有音色参考时紧跟 `音色参考@音频N`）。声音铺到听者脸上时，听者那一镜写明声音仍属原说话人、只说一次、画面里的听者闭嘴反应，写 `某某画外音继续："……"`。

### 4. 三层声音
末段以 `音效底层……；中层……；顶层……` 收束：
- **底层**：建立或改变空间感的环境声与持续低频。
- **中层**：按分镜时间顺序排列的物理声音事件，咬合起手、接触、形变、碎裂与余势；定案要求突然死寂时，写明前面建立的声音在哪一拍抽空、只剩什么微响、第一声何时回来。
- **顶层**：人声归属、口吻与语种轨道说明（无台词段按实际呼吸呼喝写或省去顶层）。

## 二、Seedance 2.5 读字经验（供准确落字，不改定案）

以下为使用中观察到的模型读字现象，用于把已定好的镜头写准；若某条经验与定案拍法冲突，报明情况由用户定夺，不自行改戏：

- **画框视野与背景推算**：每块动笔先按当前机位所在侧与朝向，从空间坐标严格推算——这个画框里能看见谁的正脸或背肩、谁在画左谁在画右、前景谁遮挡谁、背后的纵深必是什么、角色视线望向画框哪一侧、主光与逆光落在人物哪一面；镜头背后反方向的一切与未入画角色一字不写。近景、特写里若混入画框装不下的远处地标或画外人物站位，出现过模型自动把镜头拉远成全景或转回场景图原构图的现象。画外传来的铃声、台词、投到脸上的火光与探入画框的衣袖兵刃，按进入画框与声场的部分如实写。未写机位与动静处易变成站桩中景；定案要求锁死的写明 `固定机位，全程钉在此处`。
- **画面现象与句子重心**：写 `撞向画面`、`碎石扑满画面`；把 `镜头`、`镜片` 写成会碎裂的实物时，出现过画出一台摄像机的现象。有人在场的镜头以人或核心受迫物为中心，沿途景物写成从身侧掠过；拿环境做主语易生成无人的空镜（定案本就是环境空镜时照写）。
- **正面写出可见变化**：具体的物体只要写出名字，前面加 `不` 也可能被画出来；写 `看不见它本身`、`没有特效` 易让画面留空。无形的力量直接写成它迫使光线、空气、风雾、火苗、衣料、碎屑与人体发生的具体变化。不用 `不是火球、不是黑洞` 去点名不想出现的物体；仅在模型易演成默认错法、确需排除时（如晚辈对长辈说话默认演成责问），紧贴动作使用清楚的限定语。正文写 `黑屏`、`淡出` 会生成进画面并占用本条秒数；书信、屏幕等插入镜若无需展示打字浮现过程，直接写成文字已完整显示。
- **动态细节观察**：
  - 笼统写 `狰狞`、`咬牙切齿` 出现过五官变形，写成眉骨压下、下颌绷紧、青筋突起、嘴角弯起而眼底无笑等具体部位变化更稳。伤与虚弱写成正在发生的动作（擦过岩壁、手上的光一灭、换不上气），只列血迹名单易拍成静止脸；停顿里保留呼吸、眼神或手指微动防画面像卡死；偏离参考图原貌的伤损进画框时顺带点明，防被原图刷回完好。反复小动作写节奏（`指节一下一下轻叩`），写 `三下` 易机械做三下（定案指定次数时每一下单写成一个动作）。
  - 人在远景或侧面画面内张嘴说长句时，出现过动作变慢的现象；定案安排高速冲刺或飞行中说整句台词时，可用侧前方倒飞领拍（`leading tracking`）把说话人的脸、头冠与持兵手稳锁在近景中央保口型，同时让身后景物疯狂倒掠，把半句与尾字咬在交击或音爆上。
  - 飞、掠、遁只写速度易拍成头朝前双腿并拢的平趴飞，按定案写清躯干倾角与手脚姿态。快打中把每次出招逐一拆开细写易拍成轮流出招，连贯攻势合写为一串连续动作。关键接触用两三帧看清实体刃口抵死、器物受压弯曲与肩臂下挫，强光与气浪向接触点周围炸开分流、不盖住人脸与兵器接触（不用闪白吞掉命中）；慢动作全段慎用，通常只在最重一击接触瞬降至 `0.3倍速` 停半秒看清压陷裂纹、奇点坍缩或隔刃对视，立即恢复极速；蓄势写清先吸后爆，环境破坏写清先切裂压陷、后崩碎掀翻的时间差。
  - 贴脸前导、贴背尾追、翻转环绕等贴身险机位，只写运镜名出现过退回常规平拍的现象；写清主体在画框的位置、占比、距离及沿途掠过或倒转的景物更稳。

## 三、示范原件与写稿自检

落笔前对照第一段已选读的那一两篇标杆原件（若跳过第一段直接写提示词，先按本段是什么戏到 `cases/索引.md`「取哪一篇」挑一两篇读全；满殿座次、正反两张场景图另读 `cases/瑶瑶乱三界EP17/段12_截珠宣判_多宝起身.txt`、`cases/瑶瑶乱三界EP19/冷开段01_统御.txt` 的空间坐标段），照它的写法核对六样：首段怎么用一两句把因果讲完，三层各对标谁，整段的拍法与变速，空间坐标里的路线串，每一下借了上一下的什么，物件全段的账。旧原件里的 `<<<image_N>>>` 占位符现行写无后缀 `@素材名`。

**写稿自检**（交稿前由落笔者对照纯正文与实际绑定参考逐拍自查，不替代独立审片）：
1. **遮住前面的导演讲解，只读本条正文和参考，能否看懂本段要发生的事与因果？**
2. **揭示顺序是否守住了定案——观众是在选定的那一刻，凭选定的动作、画面或声音看懂的吗？**
3. **定案里最有分量的表演、力度、高潮与余势是否完整保住，每拍内容与秒数是否相称？**
4. **空间关系与物件账是否严丝合缝——每块的机位朝向、背景纵深、画左画右、视线与受光方向、前后遮挡是否与空间坐标完全自洽（无顺拐翻轴、无镜头背后景物混入）？兵器法宝在谁哪只手、缩放换手是否全段对账？**

自检通过后交付干净正文。任何修改均交付完整提示词。
